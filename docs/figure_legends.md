# Figure → code map

Template. Fill in one row per panel once the final figure order is fixed; the
goal is that a reader can go from any panel to the exact command that produced
it.

## How to use

1. Name the figure and panel exactly as in the manuscript (`Fig. 1b`).
2. Give the script, the section of `config/samples.tsv` it consumes, and any
   non-default parameter.
3. Put the intermediate files the panel was drawn from, so a reviewer can
   regenerate the plot without re-running the analysis.
